Behaviors

Every behavior is one small file in behaviors/ that tells the swarm how to move. These cards are generated live from the registry — every card below is a file a contributor shipped. Try them all in the playground.

Skins

A skin is one small file in skins/: a color palette, a dot size, a mood. Same swarm, different paint.

Formations

A formation is one small file in formations/ — nothing but a list of points on a 100×60 grid — and the swarm arranges itself into the shape. Pick one in the playground below, or type your own word and watch the swarm spell it.

How to contribute

Never opened a pull request before? Perfect — this repo is designed to be your first one. Fifteen minutes, one tiny file.

1

Fork & add one file

Fork this repo, then add one new file: a behavior in behaviors/, a skin in skins/, or a formation in formations/. Copy-paste templates are in the guide.

2

Register it

Add one line to contributions.json so the engine loads your file. That is the whole integration — no build, no wiring.

3

Open a pull request

Push, open the PR, and watch the swarm learn your trick — it shows up in the playground and on this page automatically.

// behaviors/fireworks.js — a behavior in one small file
window.SwarmRegistry.registerBehavior({
  id: 'fireworks',
  name: 'Fireworks',
  author: 'your-github-name',
  update: function (b, ctx) {
    // nudge b.vx / b.vy — that's all!
  }
});

Full step-by-step guide: CONTRIBUTING.md — or grab a good first issue.
